# 🏚️ HAUNTED MANSION — Halloween Hunt

ハロウィンの洋館に現れるモンスターを捕まえる、ブラウザで遊べるミニゲームです！ 👻🎃🦇

制限時間は60秒。画面に現れるターゲットをタップして、ハイスコアを目指しましょう！

## 🌐 Webアプリ

プレイリンク🔗：https://quickfox7.github.io/HauntedMansionShooting/

## 🎮 ゲーム概要

- **タイトル：** HAUNTED MANSION — Halloween Hunt
- **ジャンル：** カジュアル・タップゲーム
- **プレイ時間：** 60秒
- **対応環境：** JavaScriptが動作するWebブラウザ
- **操作方法：** マウスクリック・タップ

## ✨ 特徴

- 👻 **3種類のターゲット：** おばけ、かぼちゃ、コウモリが登場
- 🎯 **照準アニメーション：** ターゲットを捕獲すると、照準エフェクトが表示されます
- 🦇 **動き回るモンスター：** おばけやコウモリが画面内を移動します
- 🎃 **スコアシステム：** ターゲットごとに異なる得点を獲得できます
- ⚡ **複数のターゲット：** 最大7体まで登場し、次々と捕獲に挑戦できます
- ⏸️ **一時停止機能：** ゲームを途中で止めて再開できます
- ⛶ **全画面表示：** ゲーム画面を全画面で楽しめます（環境によっては利用できません）
- 📱 **スマートフォン対応：** タップ操作に対応したレイアウト

## 🕹️ 遊び方

1. 「ゲームスタート」を押します。
2. 画面に現れるオブジェクトをタップして捕獲します。
3. 60秒以内にできるだけ多くの得点を獲得しましょう！
4. 時間切れになったらスコアを確認し、もう一度挑戦しましょう。

### 🏆 得点表

| ターゲット | 得点 |
|---|---:|
| 🎃 かぼちゃ | +5点 |
| 👻 おばけ | +10点 |
| 🦇 コウモリ | +15点 |

コウモリは素早く移動するため、捕獲には素早い反応が必要です！

## 🚀 起動方法

### 方法1：ブラウザでプレイ

GitHub Pages リンク🔗：https://quickfox7.github.io/HauntedMansionShooting/

### 方法2：ローカル環境でプレイ

1. このリポジトリをダウンロード、またはクローンします。
2. `index.html` があるフォルダを開きます。
3. `index.html` をWebブラウザで開いてプレイします。

画像ファイルは、HTML内で指定されているパスに配置してください。

## 📁 ファイル構成


※ 実際のリポジトリに含まれるファイルに合わせて調整してください。
